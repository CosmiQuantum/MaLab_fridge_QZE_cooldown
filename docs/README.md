# Docs folder

| File | What it is | Read it when |
|---|---|---|
| `MEASUREMENT_INDEX.md` | One line per campaign with its data folders | You need to find old data |
| `log/` | The task log, one file per month, newest entry last | You append an entry, or search for a past event |
| `archive/` | The old task log and the old measurement notes up to 25 Nov 2026 | Search only. Never read whole |
| `Q5_Q6_NEXT_CHAT_HANDOFF.md` | Q5 and Q6 crossing, last status 16 Sept 2026. Lines 1 to 53 are the latest status | The crossing work resumes |
| `q5-q6-recovery-plan-20260915.md` | Closed recovery diagnostics of 15 Sept. Lines 40 to 58 list what must exist before a new crossing map | Before a new crossing map |
| `q5-q6-profile-debug-plan.md` | Closed profile debug of 15 Sept. Holds the chip design provenance | You need the design record |
| `pucq4-round-robin-closeout.md` | Result of the round robin validation of 9 Sept. What passed, what was not measured, every config value changed | You need the last full round robin record |
| `pucq4-avoided-crossing.md` | History of the first crossing scans, 9 to 14 Sept | History only |
| `pucq4-crossing-resolution-plan.md` | History of the 14 to 15 Sept continuation | History only |
| `pucq4-round-robin-validation.md` | Raw progress log of the 8 to 9 Sept campaign, 144 KB | Do not load. Use the closeout |

Everything except `MEASUREMENT_INDEX.md` and `log/` is history. Words such as ACTIVE or queued in those files describe the past. Numbers in them are seeds.

The current state lives in `harness_engineering/STATE.md`.
